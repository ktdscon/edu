1일차

웹 보안 기초와 인젝션·접근 제어 대응 (8시간)

  • 1. OWASP Top 10(2025) · API Security Top 10 개요 이해하기 (1H)
    • 2017 · 2021 · 2025 순위 변화, 신규 항목(공급망 실패, 예외 상황 처리 미흡)
    • 실습 프로젝트(Student_JWT) main 브랜치 취약점 진단 결과와 OWASP 매핑
  • 2. 실습 환경 구성 및 브랜치 기반 실습 방법 익히기 (1H)
    • 프로젝트 Clone, feature*demo 브랜치 전환 전략, curl·Postman·Burp Suite 준비
  • 3. SQL Injection 공격과 파라미터 바인딩으로 방어하기 (1.5H)
    • UNION 기반 인젝션, JdbcTemplate·JPA 네이티브 쿼리 문자열 결합의 위험
  • 4. 접근 제어 실패(IDOR) 공격과 객체 수준 인가 적용하기 (1.5H)
    • 인증과 인가의 차이, {id} 변조 공격, 소유권 검사 로직 구현
  • 5. 보안 감사 로깅과 예외 처리 하드닝 적용하기 (1H)
    • 인증 이벤트 리스너, 민감정보 마스킹, 오류 메시지 노출 차단(failclosed)
  • 6. CSRF 공격과 CSRF 토큰으로 방어하기 (1.5H)
    • 세션·쿠키 기반 요청 위조, 상태 변경 GET 제거, Thymeleaf _csrf 자동 삽입
  • 7. 1일차 정리 및 Q&A (0.5H)
2일차

인증·무결성·설정 보안 대응 (8시간)

  • 8. JWT 보안 1단계 · secret 하드닝 적용하기 (1.5H)
    • 하드코딩된 secret으로 관리자 토큰 위조, 환경 변수 분리와 약한 secret 기동 거부
  • 9. JWT 보안 2단계 · subject uuid 전환과 Refresh 토큰 적용하기 (1.5H)
    • payload의 PII 제거, 짧은 Access · Refresh 토큰(서버 저장·회전·폐기·해시 저장)
  • 10. 저장형 XSS 공격과 출력 이스케이프로 방어하기 (1H)
    • th:utext vs th:text, 입력 검증보다 출력 시점 이스케이프가 근본 대응인 이유
  • 11. 역직렬화 무결성 실패 공격과 HMAC 서명 검증 적용하기 (1H)
    • 쿠폰(Voucher) 토큰 바이트 변조로 할인율 조작, 서명 검증 후 역직렬화
  • 12. 보안 설정 오류(Actuator 노출) 진단 및 개선하기 (1H)
    • actuator/env 설정값 노출, 노출 범위 최소화와 관리자 인가 적용
  • 13. 무차별 대입(Brute Force) 공격과 로그인 시도 제한 적용하기 (1.5H)
    • Burp Suite Intruder/Repeater 공격 재현, 연속 실패 시 계정 잠금 구현
  • 14. 종합 정리 · 공급망 보안(SBOM), 보안 점검 체크리스트 (0.5H)
